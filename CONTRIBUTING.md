Before contributing to `automatic-generalization` please read our contribution standards: [Contribution Guide](docs/contributing/index.md).

### Quick Overview:
- **Code Style:** [Ruff](https://docs.astral.sh/ruff/) formats and lints the whole repository. Every check runs through pre-commit; see [docs/contributing/testing.md](docs/contributing/testing.md).
- **Naming:** Prefer descriptive variable and method names, avoid abbreviations.
- **Docstring:** Use the What / How / Why structure when needed.
- **Branching:** Work on `feature/` or `refactor/` branches when possible.
- **Pull Requests:** Each PR should be reviewed by at least one teammate.
