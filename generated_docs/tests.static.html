tests.static.test_facade_typing module

The facade hands a wrapped port out as the port type, and pyright still refuses a non-conformer there: the one cast erases nothing a caller relies on.

What: pyright, run on a fixture this test writes, accepts a conforming adapter through wrap and refuses a non-conforming one at the two places a wrapped port is handed out, an annotated assignment and a dataclass field, which is the Toolbox’s shape. The bare call, with no declared type to meet, reports nothing: the type variable solves to a union of the Protocol and the adapter, and the fixture records that gap by asserting the exact diagnostics, so a change in the checker that closes it is noticed.

How: as test_row_shape_typing.py: the fixture is written to a temporary directory, so the non-conformer is never in the pyright hook’s include list, and it imports the real wrap through the installed package.

Why: wrap returns P through a cast; if that cast or the signature ever erased the type, every hand-out would type-check and nothing in strict mode would say so.

tests.static.test_row_shape_typing module

The decorator keeps the Protocol’s structural type: ADR-0017 RS-3, under pyright.

What: pyright, run on a fixture this test writes, accepts a class that conforms to a Protocol whose method carries @row_shape and refuses one that does not, reporting exactly the non-conforming assignment.

How: the fixture is written to a temporary directory, so the deliberate non-conformer is never inside the pyright hook’s include list, and it imports the real decorator through the installed package. The project configuration and the repository root are passed explicitly, so the result does not depend on where pytest was started. Evidenced like an import contract: a case in tools/break_once/cases/ erases the decorator’s type variables and this test must then fail.

Why: a decorator that erases the method’s type makes every assignment to the Protocol type-check. Strict mode cannot show that, because an erased type is a declared Any, not an unknown, so the only evidence is a non-conformer pyright still refuses.
